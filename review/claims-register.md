# Claims register

Absolute claims — `impossible`, `guaranteed`, `nobody`, `cannot ever`,
`no one can`, `zero chance` — are load-bearing promises. Each one asserts
something an attacker, an auditor, or a court could test. This file is the list
of the ones we have actually justified.

The `absolutes` gate flags every absolute in the docs that does not appear here
verbatim. That is the point: an absolute is either registered with its
justification, or it is softened to what we can defend.

`never` and `always` are deliberately **not** in the pattern. In a normative
specification they are grammar — "a guard never calls a function" is the rule
itself, not a claim about the rule — and flagging them buried the six words
above under several hundred false positives.

Exempt files (`traps.md`, the critique and hardening reviews) are adversarial
documents whose job is to state absolutes in order to attack them.
