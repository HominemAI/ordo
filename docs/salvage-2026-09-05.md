## The one thing to get right when resuming

**Merge these branches. Never apply `git diff main..<branch>` as a patch.**

Six of the seven were cut from a `main` that predates today's merges of the
trigger layer, the group-membership surface, and the security-event
drainer. So a raw `main..branch` diff shows **thousands of deleted lines**
that are not the agent's work at all — they are the three merged features,
which a patch would silently revert. `git merge` uses the merge base and
handles this correctly; a patch does not.

Each row below gives the branch's **own** base so its real work is
readable with `git diff <base>..<branch>`.

## What must happen before any of it is merged

The same standard as everything else in this repo, and it matters more
here because nobody has read this code:

1. **`cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets
   -- -D warnings`, `cargo test --workspace`** — all three clean, against
   current `main`, not against the branch's stale base.
2. **Explain every golden that moved**, line by line. The `std.E.list`
   branch moves 1,803 lines of artifact golden; a golden that moves is a
   question, not a chore, and this project has caught real defects by
   reading a diff rather than regenerating it.
3. **Check the tests transcribe the specification**, not the
   implementation. A test written from the code passes forever and proves
   nothing. This is the corpus's one rule and an unattended agent is
   exactly the circumstance that erodes it.
4. **Check nothing was weakened to go green.** Look for shortened test
   files and relaxed assertions.
5. **Resolve `docs/roadmap-checklist.md` conflicts by reading both sides.**
   This file conflicts on nearly every merge, and resolving it by keeping
   both halves **silently re-opens items that were closed** — a mistake
   made repeatedly in this project's history. Keep each side's *completed*
   entry.
6. **Check the checklist claims match what the code delivers.** An agent
   that died mid-run may have marked an item done before finishing it.
