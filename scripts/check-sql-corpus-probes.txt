# Probes for scripts/check-sql-corpus.py.
#
# The Ordo behind entries whose doc text carries only a short inline fragment,
# or none. One probe is a line `## ID` and the lines below it, up to the next
# `##`. An ID may have several probes. A probe must compile when the entry's
# verdict is direct or problematic. It must be refused when the verdict is
# not possible, so a stale "not possible" shows up the day the language
# grows the feature.
#
# Wrapper rules are the same as for snippets in the docs (see the script).

  seats: int
  used: int = 0

  team -> teams
  who: text
